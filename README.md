# Shopping Cart

A shopping cart application built with **HTML, CSS, and Vanilla JavaScript.** Users can browse products, search for items, add products to the cart, manage quantities, and track the total order price in real time. Cart data is persisted using Local Storage.


## Live Demo

🔗 **View Online:**  
https://dorsa-piraneh.github.io/shopping-cart/

## Screenshots

![Shopping Cart Demo](./assets/images/demo.gif)


## Features

- Product listing
- Discounted price calculation
- Product search
- Shopping cart management
- Increase and decrease product quantity
- Clear shopping cart
- Real-time total price calculation
- Local Storage support
- Order quantity limit per product
- SweetAlert2 notifications

## Installation & Usage

### Option 1: Run Locally (No Git Required)
1. Download the project as ZIP.
2. Extract the files.
3. Open `index.html` in your browser.

### Option 2: Clone with Git
```bash
git clone https://github.com/dorsa-piraneh/shopping-cart.git
```
Then open `index.html` in your browser.
